# Archiv — nicht mehr gültig

Die Dateien in diesem Ordner sind die ursprünglichen Konzeptpapiere von E.D. Endpoint.
Sie sind durch [SPEC.md](../../SPEC.md) ersetzt und bleiben nur zur Nachvollziehbarkeit erhalten.

Mehrere ihrer Aussagen sind fachlich überholt oder unzutreffend (Payload-Inspektion trotz
TLS, „Hardware“-Killswitch per Treiberbefehl, SLM als Durchsetzungsinstanz, UI-Hooks als
Schutzfunktion, pauschaler Vergleich mit Defender). Die Korrekturen und ihre Begründungen
stehen in [DESIGN-DECISIONS.md](../DESIGN-DECISIONS.md).
