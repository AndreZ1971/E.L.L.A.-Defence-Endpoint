# Nachweisregister

Jede technische Aussage in EDEP ist hier mit ihrem Nachweis verzeichnet. Nichts davon muss
man glauben; alles lässt sich nachschlagen oder nachmessen.

**Stand:** 2026-10-03 · Quellen [Q-xx] siehe [SPEC.md, Anhang B](../SPEC.md#anhang-b--quellen)

| Zeichen | Bedeutung                                                                       |
| ------- | ------------------------------------------------------------------------------- |
| 📄      | Belegt durch Herstellerdokumentation oder anerkannte Referenz (MITRE, CISA)     |
| 📑      | Belegt nur durch Sekundärquelle (Benchmark, Fachartikel); Herstellerbeleg fehlt |
| 🧪      | Lokal gemessen (System, Datum, Befehl angegeben)                                |
| ⏳      | **Nicht geprüft.** Offen, mit Prüfweg                                           |

Eine Aussage mit ⏳ darf in Produktbeschreibungen nicht als Tatsache verwendet werden.
